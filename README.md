Rock-Paper-Scissors Game
Welcome to the fun and interactive Rock-Paper-Scissors game! Challenge yourself and play against the computer in this exciting twist on the classic game. This Python implementation brings a new level of engagement with animations, score tracking, and multiple rounds.

Features
Multiple Rounds: Play as many rounds as you want. The game will keep track of your score versus the computer's.

Fun Animations: Enjoy visual representations of your choices (Rock, Paper, or Scissors) with ASCII art.

Score Tracking: The game tracks the score after every round and displays the current standings.

Interactive Gameplay: Input your choice and watch the game unfold in real-time with the results.

How to Play
Start the game and choose the number of rounds you'd like to play.

Enter your choice (Rock, Paper, or Scissors).

The computer will make its choice, and the result of each round will be displayed.

The game will announce the winner of each round and update the score.

After all rounds, the game will announce the final winner based on the highest score.

Requirements
Python 3.x
